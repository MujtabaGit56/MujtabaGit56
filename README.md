## Featured projects

### [PharmRAG](https://github.com/MujtabaGit56/PharmRAG): medication Q&A grounded in FDA drug labels

Answers medication questions using only FDA-approved drug label text, so every answer can be traced back to its source.

- Searches about 100K OpenFDA drug labels, then reranks the results with a medical cross-encoder before Gemini writes the answer
- Compared general and medical-domain embeddings across 150 consumer questions; the medical version beat both the general one and an LLM with no retrieval on factuality, safety and clarity
- Streamlit interface that shows the label sections behind each answer

`Python` `PyTorch` `Hugging Face` `FAISS` `Gemini` `Streamlit`

### [Artemis Homelab](https://github.com/MujtabaGit56/artemis-homelab): self-hosted home server

A home server I built and run on a Proxmox mini PC, with about 15 services in Docker, remote access over Tailscale with no open ports, and encrypted offsite backups.

`Proxmox VE` `Docker Compose` `Tailscale` `Python`
